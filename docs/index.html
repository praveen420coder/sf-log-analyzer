Capabilities

Everything you need to debug faster

Lightning-Fast Spotlight Search Alt + T

Instantly search Salesforce Setup settings, configuration menus, and official documentation directly from the extension. Jump straight to the correct Setup page or find Apex developer docs without breaking your workflow or digging through menus.

Visual Hierarchy

Convert flat log files into an expandable tree view. Easily understand execution flow, method calls, and nested operations without getting lost in text.

Smart Filtering

Filter logs by event type (USER_DEBUG, SOQL, METHOD_ENTRY, etc.). Instantly isolate exactly what you are looking for in massive log files.

SOQL & DML Analysis

Extract and highlight all SOQL queries and DML operations. See exactly which queries are running and how many rows they return to optimize performance.

Limits Tracking

Keep an eye on Governor Limits. The analyzer highlights limits consumption as the transaction progresses, helping you spot exceptions before they happen.

Debug Sessions

Automatic session detection. Easily enable and manage debug sessions for different users directly from an intuitive dashboard.

Keyboard Driven

Navigate and trigger actions rapidly using built-in keyboard shortcuts. Designed for power users who prefer to keep their hands on the keyboard.
